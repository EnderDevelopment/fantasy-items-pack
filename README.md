# Fantasy Items Pack

The Fantasy Items Pack is a Minecraft texture pack that adds unique fantasy items to your game. This pack includes custom items like the Lev-Ei, Railgun, Shrink Snowball, and Thanos Glove, each with unique textures and functionalities. The pack is designed for Minecraft 1.20+ and includes both a data pack and a resource pack to enhance your gameplay experience.

## Install

1. Download the Fantasy Items Pack from the GitHub repository.
2. Extract the downloaded zip file.
3. Move the `data_pack` folder to your Minecraft world's `datapacks` folder.
4. Move the `resource_pack` folder to your Minecraft `resourcepacks` folder.
5. In Minecraft, go to `Options` > `Resource Packs` and enable the Fantasy Items Pack.
6. Go to `Options` > `Data Packs` and enable the Fantasy Items Pack.

## Use

1. To obtain a custom item, use the corresponding command in the `give.mcfunction` file located in the `data_pack/data/custom_items/functions` folder. For example, to get the Lev-Ei, use the command in `lev_egg/give.mcfunction`.
2. Once you have the custom item in your inventory, right-click to use its special ability.
